<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer to preload | The untrusted renderer may call only the allow-listed contextBridge `api` methods |
| preload to main | Each api method is a thin invoke on a named channel; the payload is validated in main (01-05) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02 | Elevation of Privilege | preload contextBridge | mitigate | Expose only named settings/secrets/theme methods; never expose ipcRenderer or a generic invoke (Task 2) |
| T-01-03 | Tampering | IPC payload schemas | mitigate | Zod schemas with min/max bounds for every channel; unit-proven accept/reject (Tasks 1 and 3); parsed at the handler in 01-05 |
| T-01-05 | Information Disclosure | contract/schema code | accept | The contract carries no secret material; only channel names, types, and length bounds. Secret values never appear in this layer |
</threat_model>
