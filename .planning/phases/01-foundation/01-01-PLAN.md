| Boundary | Description |
|----------|-------------|
| OS process to Electron main | Untrusted disk / environment (native binaries, prebuilds) crosses into the privileged main process |
| renderer to main | The renderer window is untrusted; only the preload contextBridge may cross (boundary is defined here structurally, enforced in 01-02 and 01-05) |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
